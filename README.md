Shortlink Studio
------------------------------------------------------------------------------------------------------------

A simple internal tool for creating and managing campaign short links.

Features
Create short links with random or custom slugs
Optional click caps
Track clicks and referrers
Search and pagination
7 day click statistics
Disable or delete links
Atomic click cap handling

------------------------------------------------------------------------------------------------------------

Tech Stack
React + TypeScript
Node.js + Express
MongoDB + Mongoose
Vite
Recharts
Vitest + Supertest

------------------------------------------------------------------------------------------------------------

Requirements
Node.js 20+
MongoDB
npm
------------------------------------------------------------------------------------------------------------
Run Locally-
in root folder run these commands-
npm install
npm run build
npm run dev
------------------------------------------------------------------------------------------------------------

Create a .env file:

MONGODB_URI=mongodb://127.0.0.1:27017/shortlink-studio
PORT=4000
CLIENT_URL=http://localhost:5173

Make sure MongoDB is running before starting the app.
